# MogQuest(モグクエスト)
## サイト概要
### サイトテーマ
各都道府県のグルメを紹介し、評価を付けて投稿できるSNS・レビュー複合サイト
​
### テーマを選んだ理由
私自身、旅行やお出かけの計画を立てる際に、グルメに特化した情報収集や比較がしづらく、参考にしやすいレビューが少ないため「どこが最適か」を判断するのに苦労した経験があります。<br>
また、周囲の意見を聞いた所、「味・価格帯・リピート率・お取り寄せの可否を知りたい」といった課題が見えてきました。<br>
これらの課題を解決するために、現地に足を運べる人はもちろん、お取り寄せなどを通じて遠方からでも楽しめるような、幅広い年代の方が快適に利用できる情報共有サイトを制作したいと思い、本テーマに決定しました。

### ターゲットユーザ
・旅行やお出かけする際、グルメの詳細な情報・レビューを効率よく比較・検索したい人<br>
・現地に行けない場合でも、お取り寄せグルメなどを通じて自宅で旅行気分や地域の味を楽しみたい人

### 主な利用シーン
・大人数や家族など様々なグループにあった旅行計画を立てたい時<br>
・気になっているグルメの価格帯・満足度といった詳細なレビューを確認したい時<br>
​・自分が訪れたおすすめグルメを投稿・紹介したい時
